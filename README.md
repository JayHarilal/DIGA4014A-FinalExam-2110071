## Introduction and Overview
A professional portfolio website developed using vanilla HTML, CSS, and JavaScript. This portfolio was created for my final exam for the Interactive Media course at the University of Witswatersrand. It serves as a showcase of myself, my skills, completed projects, and experience gained from my software development adventures.  
This portfolio was designed using frontend web development, and follows a custom design system, demonstrating:
- Responsive design
- JavaScript Interactivity
- Frontend development practices
